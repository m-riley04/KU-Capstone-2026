# requirements

This directory contains all the requirement stacks, artifacts, reference stories, and architectures.

## IMPORTANT NOTES

- The files in this directory and it's subdirectories should NOT be modified directly. The files here should only ever be the *final* copies.
- We utilize Microsoft 365 for collaboration on these documents, which does not play well with Git. To edit them, modify the shared file through OneDrive/Microsoft 365.
- For adding/modifying the requirement stack, you should utilize the [Project Kanban](https://github.com/users/m-riley04/projects/17/views/1) and then export it using the custom [GitHub Project Exporter](https://github.com/m-riley04/GitHub-Projects-Exporter), with the exported copies going in.
- The requirement stacks should be Excel tables, allowing you to easily sort the columns by sprint, story points, etc. to a custom view. This eliminates the need for trimmed requirement stacks for each sprint.
