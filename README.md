## File Structure Overview

- [docs](docs/)
  - Contains general documentation for the project.
- [media](media/)
  - Contains media and links to media for the project.
- [podwork](podwork/)
  - Contains the files for the frontend and backend for the project.
- [rpi](rpi/)
  - Contains the code and everything that will run on the physical hardware (a Raspberry Pi 5)
